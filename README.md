# 💎 BREEZY — Luxury Self-Hosted Audiophile Music Player

> **In honor of Chris Brown.** Crafted with an ultra-luxury museum exhibition aesthetic, spotlight architecture, and zero-latency audio streaming from self-hosted Proxmox infrastructure.

![Breezy Architecture](https://images.unsplash.com/photo-1614613535308-eb5fbd3d2c17?q=80&w=1200&auto=format&fit=crop)

---

## ✨ Features

- 🏛️ **Luxury Stone Exhibition Gallery:** Showcase albums in sculpted dark slate alcoves with overhead spotlights and wet reflective mirror flooring.
- 💡 **Dynamic Atmospheric Glow:** Ambient backlighting and spotlight cones smoothly adapt to the primary colors of the active album cover.
- 🎛️ **Live Audio Visualizer:** Dynamic Web Audio spectrum dancing in sync with bass and treble.
- 🎤 **Karaoke Synced Lyrics:** Real-time lyric synchronization powered by LRCLIB.
- ⚡ **Zero-Latency Proxmox Stream:** Direct chunked range streaming with instant play start (under 20ms).
- 💿 **Lossless Master Quality:** Built for true 16-bit / 24-bit 96kHz FLAC and 320kbps MP3 audio collections.

---

## 🚀 Getting Started

### 1. Run in Browser (Local Development)
```bash
# Clone the repository
git clone https://github.com/pietersensamuel088-ship-it/breezy.git
cd breezy

# Install dependencies
npm install

# Start local live server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🎵 Music Acquisition

- **Nicotine+ (Soulseek):** Pre-installed on your system for downloading full lossless discographies.
- **Direct Web Rippers:** Use Doubledouble or Lucida to grab high-res studio FLAC files directly from URLs.
